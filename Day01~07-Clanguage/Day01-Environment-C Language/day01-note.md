## 学习内容
c语言：
    |——五大分区
        |—— 栈区（stack）：静态开辟，系统自动开辟和释放空间，编译器分配和回收。主要存放：局部变量int等等类型、形参、const修饰和定
                          义的局部变量。特点：空间较小，函数执行结束自动回收
        |—— 堆区（heap）：动态开辟，需手动开辟与释放空间：调用：malloc(),calloc(),realloc()等函数开辟,free()函数释放，不释放容
                         易造成内存泄漏和内存碎片化
        |—— 全局区（静态区）：分为 .bss 和 .data。.data段：初始化值非0的全局变量、static静态变量。.bss段：未初始化 / 初始化为0的
                            全局、static静态变量程序运行全程有效；static局部变量从栈转移到此区域
        |—— 只读常量区(.rodata)：存放：字符串字面量、全局const常量。  注意：函数内部的const局部变量保存在栈，不在常量区；
        |—— 代码区(.text)：存放：编译后的程序机器指令（所有函数代码），只读。
    |——数据类型
        |——基础数据类型（按照64位操作系统下大小）
            |——char 1Byte     字符型    打印符：%c       unsigned char(无符号) 打印符：%c  
            |——short 2Byte    短整型    打印符：%hd      unsigned short(无符号) 打印符：%hu 
            |——int   4Byte    整型      打印符：%d       unsigned int(无符号) 打印符：%u 
            |——float  4Byte   低精度浮点型，有效数字6~7位，%f默认打印小数点后6位，只是显示效果，非存储限制
                |——%.10f 保留小数点后 10 位输出
                    %e 科学计数法输出
                    %g 自动精简，去除多余无效 0
            |——double 8 Byte，高精度浮点型，有效数字 15~16 位，%f打印符，标准的为%lf，精度 = 有效数字，≠小数点后的位数 
            |——long   8 Byte，长整型    打印符：%ld      unsigned long(无符号) 打印符：%lu 
            |——long long  8 Byte，     打印符：%lld      unsigned long(无符号) 打印符：%llu 
            |——数据类型转换：自动转换：char→int→float→double。强制类型转换：double→float→int→char（精度丢失）
        |——构造类数据类型
            |——数组
                |——特点：①开辟空间连续、②保存相同类型数据、③数组长度必须是常量值、④数组下标从0开始，越界报段错误（核心已转储）
                |——表现形式：类型 [ ]  
            |——指针
                |——特点：①存储16进制地址的数据类型变量、②64位操作系统下固定8字节、③定义指针变量必须初始化int*p=NULL，否则野指针。
                    ④一个指针变量可以	指向多个变量空间，多个指针变量可以指向同一个变量空间、
                    ⑤指针偏移一位，物理地址偏移一个数据类型的大小字节（如果是数组则数组空间总大小）
                    指针表现形式： 类型 *
			        数组指针：数组类型的指针，int （*p）[10]
	 				指针数组：指针类型的数组，int *p [10]
            |——结构体
                |——	特点：①使用struct关键字创建自定义数据类型、
				        ②保存多个不同数据类型的数据、
				        ③定义时不占空间，{}；后加分号
                |——结构体大小计算：先找结构体中最大成员变量类型的字节数大小，从起始位置开始，与最大成员变量字节大小作对比，如果是其
                                整数倍则相加，不是则补齐整数倍为止。最终相加，最终相加大小必须是最大基本数据类型字节大小整数倍。
            |——共用体
                |——特点：1、共用体大小：最大成员变量的整数倍(基本数据类型的大小)，2、使用union关键字创建自定义数据类型
            |——枚举
                |——特点：①通过关键字enum创建enum{a,b,c,d}; -- 默认是int类型，从0开始依次递增，如果a不初始化则：a=0、b=1……依次递
                    增。②如果赋值，则递增累加
    |——九大语句
        |——条件语句：
            |——①if(条件){代码}、if(条件){代码}else{代码}、if(条件){代码} else if(条件){代码} else{代码}；
            |——②switch(任意表达式/变量){
					case 常量1：语句1；break；
                    default：语句；break；
                    }			
        |——循环语句：
            |——for
            |——while（）
            |——do{}while（）
        |——控制语句：
            |——⑥break（跳出循环或switch语句）
            |—— ⑦continue （结束本层循环，继续下一层循环）
            |—— ⑧return  （结束函数当前函数运行/扔出返回值）
            |—— ⑨goto   在函数内跳转到指定位置 
                |——	a：		
				    goto a；
     |——32关键字
        |——数据类型关键字：
            |—— 1.  char：定义字符类型变量。
                2.	short：定义短整数类型变量。
                3.	int：定义整数类型变量。
                4.	float：定义单精度浮点数类型变量
                5.	double：定义双精度浮点数类型变量。
                6.	long：定义长整数类型变量。
                7.	signed：定义有符号整数类型变量。
                8.	unsigned：定义无符号整数类型变量。
                9.	void：定义无类型（空）的关键字。
        |——控制流程关键字：
            |—— 10. break：用于跳出循环或switch语句。 
                11. case：在switch语句中用于匹配不同的情况。
                12. continue：用于终止当前循环的迭代，继续下一次迭代。 
                13. default：在switch语句中的默认情况。
                14. do：定义do-while循环。
                15. else：在if语句中表示条件不成立时执行的语句块。
                16. for：定义for循环。
                17. goto：用于无条件跳转到指定标签处。 
                18. if：定义条件判断语句。
                19. return：从函数中返回值。
                20. switch：定义switch语句。
                21. while：定义while循环。
        |——其他关键字：
            |——22. auto：定义自动变量： 在函数内部定义的变量具有自动变量的属性。
            |——23. const：定义常量、使编译器保护不希望被改变的参数，防止参数被代码无意的修改，减少BUG出现
            |——24. extern：声明外部变量或函数。 
            |——25. register：定义寄存器变量
            |——26. static：定义静态变量或函数。
            |——27. enum：定义枚举类型。 
            |——28. struct：定义结构体类型。
            |——29. typedef：为已有类型定义新名称
            |——30. union：定义共用体类型。
            |——31. sizeof：用于获取变量或类型的大小。
            |——32. volatile：定义易变变量，告诉编译器不要优化（缓存）该变量每次读取都要从原始地址重新读取，而不是去已经缓存到的寄
                            存器里去读。因为这个变量被修饰的是易变的。
