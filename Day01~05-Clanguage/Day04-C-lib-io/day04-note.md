1、C标准字符串库函数的使用，在 C 语言的基础字符串库里，这四个被称为 “四大金刚”
    1、strlen(s)：计算字符串长度（不包括末尾的 \0）。返回值是长度。
    2、strcpy(dest, src)：把 src 拷贝到 dest（会把 \0 也拷过去）。            strncpy(dest,src.n)，末尾需要手动补充 \0
    3、strcat(dest, src)：把 src 拼接到 dest 的末尾，\0自动补齐。             strncat(dest,src,n),c从dest末尾\0位置开始拼接，需要留出\0的位置，自动补齐
    4、strcmp(s1, s2)：逐个字符比较。
        返回 0：两个字符串完全相等。
        返回 >0：s1 大于 s2。
        返回 <0：s1 小于 s2。
标准库提供了带长度限制的 n 系列版本：strncpy、strncat、strncmp。它们在拷贝或比较时，会多传一个参数：
比如 
strncpy(dest, src, 20) 表示最多只拷贝 20 个字节。
例：
    char dest[20] = {0}; // 初始化为 0
    strncpy(dest, src, sizeof(dest) - 1); // 留一个位置给 \0
    dest[sizeof(dest) - 1] = '\0'; // 【关键步骤】手动强制补上结束符！

只有strcpy是需要手动补齐（按照标准库来使用的话），如果手写的话都要注意手动补齐\0

3、结构体内成员信息的文件IO操作
---文本模式不带b
 *写系列：
    w 只写：
        文件不存在：新建文件；
        文件已存在：直接清空原有全部内容，从头覆盖写；
        只能写，不能读；
    w+ 读写：
        文件不存在：新建；存在则清空全部内容；
        既能写，也能读；写完要用 rewind() / fseek() 回到文件头才能读。
 *读系列：
    r只读：
        文件必须提前存在，否则打开失败返回 NULL；
        只能读取，不能写入修改；
    r+读写：
        文件必须存在；不清空原有内容；
        可读可写，从文件开头操作，写会覆盖原有字符。
*追加系列：
    a 追加只写
        不存在则新建；存在保留原有内容；
        只能在末尾追加，不能读；
    a+ 追加读写
        不存在新建；存在保留旧内容；
        可读可写；所有写入永远自动跑到文件尾部，读可以任意跳转。

---二进制模式（带 b，车载存结构体 / 数据必用）
    在上面基础上加 b，消除系统换行符转换差异：
    rb / rb+ / wb / wb+ / ab / ab+
    Linux 文本 / 二进制几乎无区别；Windows 必须加 b 否则结构体读写错乱；
    存储 struct、数值、日志二进制包统一用 wb/rb。

---常见文件类型（C 语言全部都能读写，只是存储格式不同）
    .txt 普通文本日志
    .c/.h 代码源文件
    .md 说明文档
    .ini/.conf 配置文本（按键、车速、设备参数）

---二进制类（必须 rb/wb，不能用文本模式）
    .bin 二进制数据（存储结构体、车辆速度、电压、设备参数，车载最常用）
    .dat 数据缓存文件
    .elf/.so Linux 可执行 / 动态库
    .jpg/png 图片资源
    .mp3 音频文件
    .log 二进制日志包
    .tar/gz 压缩包
---特殊格式（底层都是二进制）
    .csv 表格文本（可用文本模式读写逗号分隔数据）

## 遇到问题 & 解决方案
1、w/w+ 打开直接清空文件！如果只是追加日志，绝对不能用 w，要用a/a+；
2、r/r+ 打开前文件必须存在，否则返回空指针，不加判断直接崩溃；
3、读写切换必须重置文件指针：rewind(fp) 或 fseek(fp,0,SEEK_SET)；
  例：w + 模式写完直接读，读到的是空，要回到文件头；
4、存结构体、数值、图片一律用二进制 wb/rb，防止换行符篡改数据；
5、a+ 无论 fseek 跳到哪里，调用 fprintf/fwrite 写数据时，系统自动把指针拉到文件末尾追加。
6、fputs 不自带换行；fgets 会读入换行符；
7、二进制读写只用 fread/fwrite，绝对不用 fprintf/fscanf，会破坏结构体字节；
8、fscanf 遇到空格、换行、制表符都会自动分割，适合格式化文本配置。fputs 不自带换行；fgets 会读入换行符；
9、二进制读写只用 fread/fwrite，绝对不用 fprintf/fscanf，会破坏结构体字节；
10、fscanf 遇到空格、换行、制表符都会自动分割，适合格式化文本配置。
